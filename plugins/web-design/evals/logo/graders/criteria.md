PASS 需同時符合：
1. 用 SVG 向量繪製、方形畫布，提出 2～3 個概念給使用者挑。
2. 有純黑白（單色）測試與 16px 或 favicon 尺寸的辨識測試。
3. 交付清單包含 favicon（svg 或 ico）、apple-touch-icon 180×180、單色版或深淺底版本。
4. 由 Claude 自己做撞名與商標近似檢查（網路搜尋同名品牌、智慧財產局商標檢索），並把查詢範圍與結果寫進交付說明；沒有要求使用者自行去查或找事務所。
5. 明確不使用圖庫照片作為 logo 元素，且沒有使用漸層表現。
FAIL：缺少任何一項，或交付清單含 .ai、CMYK 印刷 PDF 等無法由 SVG 直接產出的檔案。
