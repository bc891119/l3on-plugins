## 概念發想：從題材長出來

1. 列出使用者世界裡的 **5～7 個實物或意象**：他們每天看的文件、工具、場所、產品本身的材質（例：咖啡店店員→點單、杯貼、手寫菜單板、集點卡）。
2. 加上**一手品牌資料**：標誌設計說明、色彩意義、機關或品牌歷史。
3. 每個方向選一個意象，寫成一句話概念，再推導出：色彩（從品牌意義或意象取色）、字型（黑體／明體／圓體的身份感）、版面語彙（紙、框、線、面）、唯一亮點。
4. 2～3 個方向要彼此真的不同（例：一個沉穩文書感、一個明亮產品感），不要只換顏色。

範例（咖啡店的線上點單）：「吧台上的一張點單，貼著杯貼」。品牌的兩個顏色各有意義 → 一色代表客人的一側（選項、備註），一色代表店家的一側（製作狀態、主要操作）；杯貼是唯一亮點，串起品項、客製選項與取餐號碼；菜單用明體。

## 唯一亮點原則

- 一個畫面只有一個讓人記住的元素（杯貼、獨特的標題字、一種圖形語彙），其餘安靜。
- 亮點要有功能（標示狀態、品牌識別、引導主要行動），不是純裝飾。
- 拿掉一件飾品：定稿前檢查有沒有兩個記號在講同一件事，有就拿掉一個。

## AI 範本特徵（避免）

看到這些就是「像 AI 做的」，方向稿不要出現：

- Inter／系統字當唯一字型，紫藍漸層背景或按鈕
- 米色底＋赤陶橘、玻璃擬態、霓虹發光
- 置中大標＋漸層光暈＋兩個按鈕的英雄區
- 三欄「圖示＋標題＋一句話」特色區，每張卡片都有陰影與大圓角
- 表情符號當圖示；圖示粗細、風格混用
- 所有區塊同樣的留白與卡片，沒有層級
- 只有線條的空殼（太克制也是範本感：看不出這是誰的網站）

## 參考庫用法

| 用途 | 去哪裡 | 怎麼用 |
|---|---|---|
| 真實產品的頁型與流程 | Mobbin（app／web，付費）、Refero（依頁型與元件分類） | 找 3 個同類產品的同一頁型，列出共同做法與差異 |
| 視覺方向 | Land-book、Recent（原 Godly）、Lapa Ninja | 只借概念與手法，不抄版面 |
| 政府／公共服務 | 日本數位廳 DADS、英國 GOV.UK Design System | 排版、表單、無障礙做法 |
| 字型搭配 | Google Fonts、Typewolf | 中文先確定黑體／明體，再配英文 |

參考只能借「為什麼有效」，寫進方向稿說明；不要複製特定網站的版面、插圖或品牌元素。

## 退件追問

使用者說「不好看」「沒感覺」但說不出原因時，用 AskUserQuestion 一次問 1～2 題，每題給具體選項：

- 哪個方向偏了：太素／太花、太冷／太可愛、太像範本、層級不清楚、字太小或太擠
- 想往哪裡推：更有溫度（暖色、明體、手繪感）／更專業（深色、黑體、網格）／更大膽（大字、強對比、不對稱）
- 有沒有一個參考網站「就是要這種感覺」

問出來後只改那一點，附前後對照截圖。
